# EasyBook

Контекст онлайн-сервиса бронирования отелей и анализа результатов бронирования.

## Язык

**Тип номера**:
Категория размещения в отеле, которую выбирает и бронирует клиент; отдельный физический номер не выделяется.
_Избегать_: Конкретный номер, экземпляр комнаты

**Описание типа номера**:
Обязательный краткий текст об особенностях типа номера, который клиент читает при выборе размещения.
_Избегать_: Описание конкретного номера

**Имя пользователя**:
Обязательные имя и фамилия владельца учётной записи, которые он указывает при регистрации. Оба значения хранятся отдельно и не могут быть пустыми.
_Избегать_: Никнейм, единое поле полного имени

**Аналитический отчёт**:
Набор агрегированных показателей деятельности, в котором каждый существующий отель представлен отдельным элементом, даже если за отчётный период у него не было активности.
_Избегать_: Общий отчёт, сводка по сервису

**Отчётный период**:
Полуоткрытый интервал дат проживания, в который включаются ночи начиная с даты начала периода и до даты его окончания, не включая её.
_Избегать_: Период создания броней

**Ночь в отчётном периоде**:
Ночь проживания по подтверждённой брони, попавшая в пересечение срока брони с отчётным периодом. Отменённая бронь не создаёт забронированных ночей.
_Избегать_: Полный срок пересекающей период брони

**Расчётная выручка отеля**:
Стоимость ночей по подтверждённым броням отеля, попавших в отчётный период. Она не подтверждает факт оплаты; отменённые брони не создают расчётную выручку.
_Избегать_: Фактическая выручка, стоимость всех созданных броней

**Процент отмен**:
Доля отменённых броней среди всех подтверждённых и отменённых броней отеля, пересекающих отчётный период. При отсутствии таких броней равен нулю.
_Избегать_: Доля отменённых ночей

**Окно отмены**:
Период до даты заезда, в течение которого подтверждённую бронь можно отменить. Начиная с даты заезда отмена недоступна.
_Избегать_: Отмена после начала проживания, частичная отмена

**Средняя оценка отеля**:
Среднее значение оценок по завершённым проживаниям в отеле, дата выезда которых попала в отчётный период. Дата публикации отзыва не определяет его отчётный период; при отсутствии оценок среднее отсутствует.
_Избегать_: Средняя оценка опубликованных за период отзывов
