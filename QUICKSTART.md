# 🚀 Быстрый старт EasyBook

## Запуск приложения за 5 минут

### 1. Установите зависимости фронтенда

```bash
cd frontend
npm install
```

### 2. Запустите фронтенд

```bash
npm run dev
```

Фронтенд будет доступен по адресу: **http://localhost:5173**

### 3. Запустите бэкенд (в другом терминале)

```bash
# Вернуться в корень проекта
cd /home/user/EasyBook

# Активировать виртуальное окружение (если есть)
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows

# Убедитесь что PostgreSQL и Redis запущены
# Затем запустите бэкенд
python -m src.main
```

Бэкенд будет доступен по адресу: **http://localhost:8000**

### 4. Готово! 🎉

Откройте браузер и перейдите на **http://localhost:5173**

## Что вы можете сделать:

1. **Зарегистрироваться** - создайте новый аккаунт
2. **Войти** - войдите с вашими данными
3. **Искать отели** - используйте фильтры на главной странице
4. **Просмотреть детали** - кликните на отель чтобы увидеть номера
5. **Забронировать** - выберите даты и забронируйте номер
6. **Мои бронирования** - посмотрите историю ваших бронирований

## Возможные проблемы

### Фронтенд не запускается
- Убедитесь что Node.js установлен: `node --version`
- Попробуйте удалить `node_modules` и установить заново: `rm -rf node_modules && npm install`

### Бэкенд не запускается
- Проверьте что PostgreSQL запущен
- Проверьте что Redis запущен
- Проверьте настройки в `.env` файле

### CORS ошибки
- Убедитесь что бэкенд запущен на порту 8000
- Убедитесь что фронтенд запущен на порту 5173
- Перезапустите оба сервера
